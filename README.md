# 🧑‍💻 180 Days of Coding

A 180-day coding journey focused on consistency, problem-solving, and improving programming skills through daily practice.

## 📈 Challenge Progress

- ⬜ **Level 1:** Days 0–30 - Complete!
- ⬜ **Level 2:** Days 31–60 - Ongoing..
- ⬜ **Level 3:** Days 61–90
- ⬜ **Level 4:** Days 91–120
- ⬜ **Level 5:** Days 121–150
- ⬜ **Level 6:** Days 151–180

Each level is marked complete once all 30 coding days within that phase are completed.

## 📂 Repository Structure

Each 30-day phase contains folders organized by coding days/ topic covered, with the programs and practice exercises completed on those days.
